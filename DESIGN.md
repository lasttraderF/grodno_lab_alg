# Дизайн прототипа 2.1

Основная ссылка Refero: Customer.io, стиль 80dfc59f-6542-4f24-bf35-02e294f51225. Сохранены светлый серый фон, белые поверхности, текст #00262b, тонкие границы, малые радиусы блоков и округлые кнопки. #abffae применяется к взаимодействиям и фокусу. Рабочая плотность адаптирована к таблицам лаборатории.

Ссылка структуры: Attio, экран 361d1d78-a133-43a7-b1ca-52a9ee163e15. Заимствованы боковая навигация, таблицы с фильтрами и ясная иерархия строки. Цвета Attio не переносились.

Ссылка последовательности: Refero flow 4186, Create project and activate. Заимствованы явное завершение действия, обновление активного контекста и короткое сообщение результата.

Решения: основные функции разделены по кабинетам на основе требований пользователя. Большие партии используют страницы по 50 строк. Данные заказчика скрыты в DOM рабочего задания исполнителя; настоящая серверная защита находится за пределами демоверсии. Логотип и все элементы интерфейса созданы средствами SVG/HTML/CSS; растровая графика не требуется.

Проверка: стартовый экран, рабочие кабинеты, частичная приёмка, обезличенные результаты и документ проверены в браузере. Логика регистрации, разрешений, повторов и снимков документа проверяется отдельно. Мобильные стили заданы медиазапросами; настоящая мобильная камера не используется.

Изменение 30.10.2026: по пожеланию пользователя статус окрашивает всю строку заявок, проб, заданий, реестра, хранения и версий документов. Основа Customer.io и структура Attio сохранены. Дополнительный источник — Refero Color Guide: приглушённые семантические поверхности, тёмный текст, предсказуемое затемнение при наведении. Цвет взаимодействий #abffae не используется как токен статуса.
