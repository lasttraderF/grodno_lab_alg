# Альгимед ЛАБ — прототип регистрации образцов

Кликабельный статический прототип процесса от предварительной заявки до регистрации проб. Интерфейс на русском языке, без сборки и зависимостей.

## Запуск

Для запуска одним файлом скачайте `algimed_lab_prototype.html` и откройте его в браузере. Также можно запустить версию из отдельных файлов через локальный сервер в корне репозитория:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).

## Роли и сценарии

- **Менеджер:** создаёт предварительную заявку, добавляет несколько проб и выбирает исследования; видит свои заявки. Кнопка камеры показана как будущая функция.
- **Лаборант:** принимает или отклоняет отдельные пробы с причиной, добавляет незаявленную пробу, создаёт заявки и работает с реестром. Раздел импорта Excel демонстрационный.
- **Руководитель:** видит возможности лаборатории и может исправить обозначение зарегистрированной пробы с записью причины в истории.

Официальный номер заявки и номера принятых проб назначаются при подтверждении приёмки. В реестре есть поиск, фильтр по направлению и экспорт CSV.

## Границы демоверсии

Данные хранятся в `localStorage` текущего браузера и не синхронизируются между устройствами. Роли здесь демонстрационные: входа по учётной записи и серверной проверки прав нет. Камера и импорт Excel пока не подключены. Предзаполненные заявки вымышленные; исходные DOCX и XLSX в репозиторий не включены.

Отдельный файл для демонстрации: `algimed_lab_prototype.html`. Исходные файлы версии с ресурсами: `index.html`, `assets/catalog.js` и `assets/logo.svg`.
