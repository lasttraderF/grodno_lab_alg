# Альгимед ЛАБ

Кликабельный прототип 2.1 по обновлённой архитектуре лаборатории. Все примеры вымышленные.

Откройте `dist/index.html` в браузере. Это самостоятельный файл без внешних зависимостей.

В нём доступны кабинеты менеджера, приёмки, исполнителя и руководителя, а также просмотр аналитики. В разделе «Сценарии прототипа» находятся 18 точек входа в процесс. Новые данные сохраняются в браузере. Настоящий штрихкод, приборы, ЭЦП и общая серверная база не подключены. Документы показываются как демонстрационные и не предназначены для реальной выдачи.

Исходники находятся в `src/`. Сборка: `python3 bundle.py`. Проверки бизнес-правил: `node tests/model.test.cjs`.

Данные пользовательских заявок и выданные файлы не отправляются из прототипа. Переключение роли служит демонстрации, а не настоящей проверке доступа.

### Оплата в приёмке и вставка из Excel

В карточке отправленной заявки приёмка и руководитель могут менять статус в блоке «Оплата»: «Предоплата не требуется», «Ожидается оплата», «Оплачено». Ожидание оплаты блокирует передачу и выполнение испытаний, но не приём и регистрацию материала. Изменения сохраняются с сотрудником, временем и прежним значением; старые демонстрационные записи с флагом hold поддерживаются. Это ручная отметка статуса, без банковской интеграции.

На шаге «Партия проб» кнопка «Вставить из Excel» принимает скопированные ячейки без заголовков и порядковых номеров. Для инфекционных проб колонки: группа, материал; для генетики дополнительно первая колонка — индивидуальный номер животного; для продукции — наименование. Перед вставкой виден пример и предпросмотр. По умолчанию строки добавляются; замена всего списка выбирается отдельно. Исследования и вид источника берутся из общих значений партии.
