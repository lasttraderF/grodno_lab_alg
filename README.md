# Альгимед ЛАБ

Кликабельный прототип 2.1 по обновлённой архитектуре лаборатории. Все примеры вымышленные.

Откройте `algimed_lab_prototype_v2.html` или `index.html` в браузере. Это самостоятельный файл без внешних зависимостей.

В нём доступны кабинеты менеджера, приёмки, исполнителя и руководителя, а также просмотр аналитики. В разделе «Сценарии прототипа» находятся 18 точек входа в процесс. Новые данные сохраняются в браузере. Камера, настоящий штрихкод, приборы, ЭЦП и общая серверная база не подключены. Документы показываются как демонстрационные и не предназначены для реальной выдачи.

Исходники находятся в `src/`. Сборка: `python3 bundle.py`. Проверки бизнес-правил: `node tests/model.test.cjs`.

Данные пользовательских заявок и выданные файлы не отправляются из прототипа. Переключение роли служит демонстрации, а не настоящей проверке доступа.

Предыдущая версия сохранена в `algimed_lab_prototype.html`.
